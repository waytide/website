# reference-material

Material the site will carry that is **not yet a page**. Each file here is written to be read as
it stands, and how it becomes a page is not settled — the content-areas aspiration records that as
open.

**It is not `content/`.** Hugo publishes what is under `content/`, and nothing here is published.
A file moves out of this directory when its place on the site is decided, not before.

**It is not a record directory either.** Nothing here states what happened. The Waytide working
directories under `waytide/local/` hold the records — the log, the aspirations, the work session
records — and a file here is expository writing about the system rather than evidence of work
done on it.

## What it holds

- **`hinge-cycle-example.md`** — a worked example of Design By Efferent's loop, written as a
  session a reader follows from the first request to a published gem. It is an example rather
  than a record: the retry count, the client, and the version numbers are invented.
- **`vocabulary-hierarchy.md`** — the order Waytide's vocabularies decide in, what sits at each
  level, and what a vocabulary holds. `foundation`'s vocabulary-convention rule is the authority,
  and the file describes it.

## What belongs here

**Writing about Waytide that a reader could learn from, before anyone has decided where it goes.**
Two things follow from that.

- **It describes rather than binds.** The rules bind, and they live in the Waytide packages. A
  file here restates what a rule settles so a reader outside the system can follow it, and it
  names the rule as the authority.
- **It goes stale the way any hand-written description does.** That is the drift the
  self-explanation aspiration exists to remove, by driving both surfaces from one source. Until
  that is built, a file here is maintained by hand and is worth checking against the rule it
  describes.
