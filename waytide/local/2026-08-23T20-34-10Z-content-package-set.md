## Why this record exists

**The set is unchanged and one name in it moved.** Waytide renamed the grouping that holds its
extensions and externals from `tools/` to `ext/` on 2026-08-23, so the Ruby package installs at
`waytide/system/ext/ruby-lang`. The `**Inactive:**` line named the old path.

**A declaration is written rather than edited**, per the a-project-declares-its-package-set rule.
The earlier record stands as what this project declared at 10:16 UTC, and this one is what holds
now. Reverting or changing the set again is another record.

## Why this set

**This project's product is prose and pages.** It is a Hugo site with the Hextra theme. What is
written here is articles, documentation, and the material of a site, and the conventions that
govern how that is written are the ones this set keeps.

**`ext/ruby-lang` is deactivated.** It is installed and this project writes no Ruby.

**`design-by-efferent` and `testing` are deactivated.** The five hinges are a design method for a
unit of code, and controls-based test conventions have nothing here to reach.
